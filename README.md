## 🌾 Crop Yield Prediction

AgriPredict-AI includes a machine learning module that predicts crop yield from agricultural input data.

### Features
- Uses a trained machine learning model to estimate crop yield.
- Loads the saved model from the `models/` directory.
- Integrates with the AgriPredict-AI application.
- Works alongside the tomato disease detection module.

### Model Files
- `models/crop_yield_model.joblib`
- `models/crop_yield_model.json`

### How to Run
1. Run `Start_AgriPredict.bat` from the project folder.
2. Open the local application in your browser.
3. Enter the required agricultural inputs.
4. Submit the form to view the prediction.
